# CONTENT — every user-facing string, by route and locale

Extracted from the rendered DOM (text nodes plus `placeholder`, `alt` and `aria-label`),
not from the templates, so what is listed is what a visitor actually sees.

**Flagging.** The specification that governs this build is `docs/design-package-v1/FINAL-CONTENT.md`
in the `memorycarearmenia-prog/memorycare` repository. It defines a keyed English string set for a
different information architecture entirely (Pricing, How it works, Sample report, Family Circle,
Guarantees, About, Contacts, Consultation, Payment, four legal pages). **No string on
mc.makyan.com carries a key from that specification, because none of the specified screens exist.**
Rather than flag all ~430 strings individually as unkeyed, this document states that once, here, and
then flags the categories that matter: placeholder text, invented proof, stale prices, and strings
in the wrong script.
