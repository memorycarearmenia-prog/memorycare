## Два дефекта самой съёмки

**Зеркальное отражение** на `06.jpg` и `09.jpg` — текст идёт справа
налево. Это дефект снимка, не сайта.

**Пустые полотна** на `12–14.jpg`: при съёмке длинной страницы не
сработала отложенная загрузка изображений, и большая часть вышла белой.
Для разбора годятся отдельные снимки по блокам, не эти.
