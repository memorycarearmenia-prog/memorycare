Основная форма

Поло — оливковое

Ткань: пике cotton-poly, дышащая. Цвет: олива, антрацитовая отделка ворота/планки. Лого: левая грудь — эмблема + «MemoryCare» (вышивка, cream, ~8 см). Спина — эмблема ~22 см + слоган.
Межсезонье / прохлада

Куртка-софтшелл — антрацит

Ткань: софтшелл, ветро-/влагозащита. Цвет: антрацит, оливковые молния и плечевые канты. Кепка: олива + антрацитовый козырёк, эмблема спереди (cream).
Рабочий слой

Фартук-жилет с карманами

Фартук: плотный канвас/кордура, антрацит, оливковые лямки и кант кармана — для инструмента и расходников. Летняя футболка: cream с оливковой эмблемой — для жары.
Детали и правила

Айдентика на форме

Принцип: одна одноцветная эмблема, минимум текста, спокойные тона. Сотрудник выглядит как аккуратный профессионал, а не «ходячий баннер».
Почему так. Полевые команды работают на кладбище — форма должна быть узнаваемой и уважительной, а не рекламной. Оливково-антрацитовая гамма читается спокойно и природно (сходится с эстетикой бренда и line-art эмблемой), cream-эмблема даёт мягкий контраст без кричащего белого. Комплект по погоде: поло / летняя футболка → фартук-жилет для работы → софтшелл в прохладу; кепка и ID-бейдж для узнаваемости и доверия клиента на месте.
