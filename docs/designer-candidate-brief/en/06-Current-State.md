# Current state — what we're starting from

## What's wrong with the current site (this is exactly what this brief fixes)

The current site is a temporary landing page, built before the product
took its current shape. Concrete problems the new design has to fix:

- Empty temporary placeholders instead of real photos and contacts.
- No client cabinet (personal page) and no payment.
- No before/after cases.
- The visual doesn't live up to the premium price point — the site
  feels cheaper than the service actually costs.
- A weak mobile version — while mobile is the primary channel for this
  audience (see "Company and Audience").

This isn't an abstract style preference — it's a direct list of what the
new design is expected to fix relative to the current state.

## The live site as a reference (with an important caveat)

There's a current version of the site at
`memorycarearmenia.netlify.app`. **Important:** as of this brief's
compilation date (14.08.2026), it reflects an earlier revision of the
product — the old tagline, the old pricing lineup (3 tiers instead of 4,
without "Զննում"), a 4-language switcher instead of 3. The current facts
are only in this briefing package (sections 01–05), not on the live
site. It's worth looking at only for a general sense of structure/feel —
"what's already been tried" — not as a source for the current tagline,
pricing, or languages.

## More on the symbol — why these specific elements

The meaning we like in the reference sketch, and want preserved through
any redesign (even if you propose a different form): the logo reads as
three layers nested inside one another. The forget-me-not — memory. The
Armenian eternity symbol — identity, national context. The two hands —
care. Soft linear graphics, a light tonality — deliberately not a
funeral aesthetic.

Practical requirement for the vector redraw: the symbol must stay
legible at small sizes — favicon, a badge on the crew uniform.
Simplifying detail for that purpose is fine, as long as the three layers
stay recognizable.
