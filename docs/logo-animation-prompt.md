## Смысл, который должно передавать движение

Не «логотип крутится», а **«о месте памяти заботятся прямо сейчас, тихо и
постоянно»**. Три смысловых слоя движения, каждый — отдельная метафора:

1. **Руки** — фундамент, опора. Движение = поддержка, а не жест приветствия.
2. **Символ вечности за цветком** (кольца/лопасти) — непрерывность заботы
   во времени: не «вращение как эффект», а «время идёт, уход продолжается».
3. **Незабудка в центре** — то, о чём заботятся: живая, дышащая, хрупкая,
   но ухоженная. Здесь должна читаться нежность и внимание к деталям.

Референс тона — то, что уже зафиксировано в брендбуке: тёплый, но не
слащавый; спокойный и достойный; **никакого «вау-эффекта», никакой
рекламной энергии.** Это не логотип стартапа — это тихий, доверительный
знак.

## Хореография (покадрово, по слоям)

### Слой 1 — Символ вечности (кольца/лопасти), фон
- **Сверхмедленное непрерывное вращение**: один полный оборот за **50–70
  секунд**. На глаз это должно читаться не как «крутится», а как «едва
  заметно движется, если приглядеться» — как минутная стрелка часов.
- Если графика — несколько отдельных колец/дуг разных радиусов (как на
  живом сайте): каждое кольцо вращается на **своей** скорости и в **своём**
  направлении (часть по часовой, часть против) — создаёт эффект «нескольких
  слоёв времени», а не одного жёсткого диска.
- Если графика — 8-лопастная вертушка (как в этом репо): вращать **всю
  группу как одно целое**, не по отдельности (иначе лопасти визуально
  «разъедутся» и потеряют форму символа) — та же сверхмедленная скорость.
- **Категорически нельзя:** быстрое вращение (даже «средняя» скорость
  превращает символ вечности в игрушку-вертушку — теряется весь смысл).

### Слой 2 — Незабудка (центр)
- **Дыхание**: мягкое масштабирование 100% → 102% → 100%, цикл ~4–5 секунд,
  easing — плавный синус/spring (без пружинного перехлёста — см.
  `brand-video.md`: `spring(damping:200)`, никакого «boing»).
- **Тычинки в центре** (точки на концах): едва заметное мерцание —
  opacity 85%→100%→85%, **не синхронно** у всех точек, а с небольшим
  случайным сдвигом по фазе (0.3–0.8 с разброс) — читается как живое
  подрагивание/внимание к деталям, а не как строб.
- Лепестки не двигаются независимо от общего «дыхания» — цветок должен
  оставаться одной цельной формой, не «трепетать» лепестками по отдельности
  (это выглядело бы тревожно/ветрено, а не спокойно).

### Слой 3 — Руки
- **Едва заметное «дыхание опоры»**: вертикальное смещение ±2 px, цикл
  6–8 секунд, чуть медленнее и **не синхронно** с дыханием цветка (руки —
  это опора, они должны быть чуть более «неподвижны», чем то, что они
  держат — иначе теряется ощущение устойчивости).
- Никакого раскрытия/закрытия ладоней, никакого «поднятия рук в кадр» в
  фоновом (idle) состоянии — это уже опора, а не жест.

### Слой 4 — Свет (опционально, если инструмент поддерживает градиенты/маски)
- Раз в **8–10 секунд** — очень мягкий диагональный блик (linear-gradient
  highlight), проходящий через всю эмблему за ~1.5–2 секунды, как утренний
  свет, скользнувший по линиям. Прозрачность блика низкая (~15–20%), чтобы
  не выглядеть как «глянцевая реклама».
- Если инструмент не умеет такой блик — просто пропустить этот слой, он не
  обязателен.

## Момент появления (если это hero-заставка при загрузке страницы)

Если эмблема анимируется **один раз при заходе на сайт**, а потом переходит
в фоновый цикл выше:

1. Руки — едва заметно «оседают» на место снизу вверх (±10px), 0.6 с,
   spring, без отскока.
2. Символ вечности (кольца/лопасти) — **прорисовка линии** (SVG
   stroke-dasharray/stroke-dashoffset «рисование от руки»), 1.2–1.5 с,
   слева направо или от центра наружу.
3. Незабудка — раскрывается из полу-сомкнутого бутона в полный цветок за
   ~1 с, **после** того как символ вечности дорисовался (не одновременно —
   должна читаться последовательность: сначала время/постоянство, потом
   то, о чём заботятся).
4. Дальше — переход в фоновый цикл (слои 1–4 выше), без рывка.

Общая длительность появления: **~3 секунды**. Дальше — бесконечный тихий
цикл.

## Технические требования

- **Формат:** предпочтительно SVG/CSS-анимация (или Lottie) — векторное,
  лёгкое, чёткое на любом экране, поддерживает прозрачный фон. Если вставка
  идёт через AI-видео-инструмент — экспортировать WebM с альфа-каналом или
  MP4 с петлёй (без видимого шва в точке зацикливания).
- **Длительность одного бесконечного цикла:** 50–70 секунд (задаётся
  скоростью вращения символа вечности — самый медленный слой определяет
  длину цикла для бесшовной петли; дыхание цветка/рук зациклено на более
  короткий период внутри этого).
- **Частота:** 30 fps достаточно (это не быстрое движение).
- **`prefers-reduced-motion`:** обязательно уважать — статичный вариант
  (например, только тихое мерцание тычинок, без вращения и без дыхания)
  для пользователей с этой настройкой.
- **Цвета:** без изменений — оливковый `#5E6A3A`/`#7C8654`, светлый
  антрацит `#33373C`/`#6B7075`, тёплый белый `#FAFAF7`. Никаких новых
  цветов, никакого неонового свечения/drop-shadow.

## Слова-ориентиры (для AI-инструмента, если генерация видео/анимации текстовым промптом)

«tending», «quiet continuity», «breathing, not spinning», «a caretaker's
patience», «barely-there motion», «morning light passing over line art»,
«heartbeat-slow», «dignified, not decorative».

## Что нельзя (ломает смысл)

- Быстрое или заметное вращение символа вечности — превращает вечность в
  «вертушку»/игрушку.
- Пружинный «boing»-отскок на дыхании цветка или появлении рук — это не
  весёлая анимация, это уход.
- Мигание/строб тычинок в унисон — читается как ошибка/глюк, а не как
  «живой огонёк внимания».
- Частицы, конфетти, вспышки, блеск/сияние поверх цветка — про уход, не
  про праздник.
- Звук по умолчанию (autoplay с аудио).
- Любое изменение геометрии эмблемы «в процессе» анимации (лепестки не
  меняют форму, руки не меняют форму ладони) — только положение/масштаб/
  прозрачность/вращение целиком.

## Готовый CSS-каркас (под текущую SVG-структуру `index.html` этого репо — 8-лопастная вертушка)

Применимо, если эмблема уже обновлена до варианта с лопастями (`<symbol
id="mc-emblem">` в `index.html`). Группы уже разделены в разметке:
лопасти-вертушка — одна `<g>` с `transform="translate(60,58)
scale(0.82)"`; руки — отдельная `<g>`; незабудка — отдельная `<g>`.

```css
/* Оборачивающий div/svg должен иметь фиксированный transform-origin: center */

@keyframes mc-eternity-spin {
  from { transform: translate(60px,58px) scale(0.82) rotate(0deg); }
  to   { transform: translate(60px,58px) scale(0.82) rotate(360deg); }
}
.mc-eternity-group {
  animation: mc-eternity-spin 60s linear infinite;
  transform-origin: 60px 58px;
}

@keyframes mc-flower-breathe {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.02); }
}
.mc-flower-group {
  animation: mc-flower-breathe 4.5s ease-in-out infinite;
  transform-origin: 60px 56px;
}

@keyframes mc-hands-breathe {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-2px); }
}
.mc-hands-group {
  animation: mc-hands-breathe 7s ease-in-out infinite;
}

/* Тычинки — мерцание с разным фазовым сдвигом на каждую точку */
@keyframes mc-stamen-flicker {
  0%, 100% { opacity: 0.85; }
  50%      { opacity: 1; }
}
.mc-stamen-dot:nth-child(1) { animation: mc-stamen-flicker 3.2s ease-in-out infinite; }
.mc-stamen-dot:nth-child(2) { animation: mc-stamen-flicker 3.6s ease-in-out infinite -0.4s; }
.mc-stamen-dot:nth-child(3) { animation: mc-stamen-flicker 4.1s ease-in-out infinite -0.9s; }
/* ...и т.д. на каждую точку, со случайным небольшим сдвигом */

@media (prefers-reduced-motion: reduce) {
  .mc-eternity-group, .mc-flower-group, .mc-hands-group,
  .mc-stamen-dot { animation: none; }
}
```

Если графика на сайте — кольца (текущий живой вариант), логика та же, но
на **каждое** кольцо/дугу — свой `animation-duration` (например 45s, 60s,
75s, в разные стороны через `animation-direction: reverse` на части колец)
вместо одной общей группы.
