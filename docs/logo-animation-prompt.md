# MemoryCare — промпт анимации логотипа-эмблемы (главный hero-визуал)

> Обновлено 03.08.2026 (v2): владелец подтвердил кольца/дуги как реальную
> графику логотипа (прислал чистый рендер эмблемы — то же кольцевое
> построение, что и на живом сайте). Промпт ниже написан именно под этот
> вариант. Добавлено жёсткое требование: **бесшовная бесконечная петля** —
> ни начала, ни конца видно быть не должно. Палитра/геометрия не меняются;
> меняется только моушн.

---

## Смысл, который должно передавать движение

Не «логотип крутится», а **«о месте памяти заботятся прямо сейчас, тихо и
постоянно»**. Три смысловых слоя движения, каждый — отдельная метафора:

1. **Руки** — фундамент, опора. Движение = поддержка, а не жест приветствия.
2. **Кольца/дуги за цветком** (символ вечности) — непрерывность заботы во
   времени: не «вращение как эффект», а «время идёт, уход продолжается».
3. **Незабудка в центре** — то, о чём заботятся: живая, дышащая, хрупкая,
   но ухоженная. Здесь должна читаться нежность и внимание к деталям.

Тон — как уже зафиксировано в брендбуке: тёплый, но не слащавый; спокойный
и достойный; **никакого «вау-эффекта», никакой рекламной энергии.** Это не
логотип стартапа — это тихий, доверительный знак.

## ⚠️ Главное требование: бесшовная петля (без видимого начала/конца)

Это не «пожелание», а инженерная задача, которую нужно решить математикой,
а не «на глаз». Правило: **если анимация состоит из нескольких независимых
движений (кольца вращаются, цветок дышит, руки дышат, тычинки мерцают),
то бесшовно зацикливается только весь набор целиком, если у КАЖДОГО
движения период — это точный делитель одной и той же общей длительности
цикла.** Иначе один слой «доедет» до петли идеально, а другой — нет, и
будет виден микро-рывок в момент склейки.

**Общая длительность петли: 60 секунд.** Все параметры ниже выбраны так,
чтобы ровно в 60-й секунде каждый слой возвращался **в точности** в своё
начальное состояние (для колец — та же самая угловая ориентация; для
дыхания — тот же кадр цикла; для мерцания — та же фаза):

| Слой | Движение | Период | Циклов за 60с | Направление |
|---|---|---|---|---|
| Кольцо A (самое светло-серое, наружное) | вращение | 60с | 1 | по часовой |
| Кольцо B (серое, среднее) | вращение | 30с | 2 | против часовой |
| Кольцо C (тёмно-антрацитовое) | вращение | 20с | 3 | по часовой |
| Кольцо D (оливковое светлое) | вращение | 60с (фазовый сдвиг -15с) | 1 | против часовой |
| Кольцо E (оливковое тёмное, самое маленькое) | вращение | 15с | 4 | по часовой |
| Незабудка (весь цветок) | дыхание, масштаб 100→102% | 5с | 12 | — |
| Руки | дыхание, ±2px по Y | 7.5с | 8 | — |
| Тычинки, точка 1 | мерцание opacity | 4с | 15 | фазовый сдвиг 0с |
| Тычинки, точка 2 | мерцание opacity | 5с | 12 | фазовый сдвиг −1.2с |
| Тычинки, точка 3 | мерцание opacity | 6с | 10 | фазовый сдвиг −2.7с |
| Тычинки, точка 4 (и далее) | мерцание opacity | 7.5с | 8 | фазовый сдвиг −0.6с |
| Свет/блик (опционально) | диагональный highlight | 10с | 6 | — |

Почему это работает: 60 делится нацело на 60/30/20/15/10/7.5/6/5/4 без
остатка — то есть каждый слой в момент t=60с оказывается ровно там же, где
был в t=0с. Разные периоды и разные направления вращения между кольцами
дают эффект «нескольких слоёв времени» (кольца движутся не синхронно друг
с другом), но при этом **весь ансамбль** возвращается в исходное состояние
одновременно — переход из 60-й секунды в 0-ю становится математически
неотличим от продолжения, шва не видно.

**Практическое правило при реализации:** если меняете любую из этих
цифр — новое число тоже должно быть делителем общей длительности петли
(60, 45, 40, 30, 24, 20, 15, 12, 10, 7.5, 6, 5, 4, 3, 2, 1). Не берите
случайные периоды вроде «6.3 секунды» — петля не сойдётся.

### Если генерация идёт через AI-видео-инструмент (не через код)

Текстовый промпт для видео-генератора (Veo/Kling/аналоги) **не может
гарантировать** математически точную петлю — модель не считает периоды.
Рабочий обходной путь:
1. Сгенерировать ролик длиной с запасом (например 75–90 секунд) с этим же
   описанием движения.
2. В монтаже взять стабильный средний участок (не первые/последние
   секунды — там честная стабилизация ещё не устоялась) и сделать
   **кроссфейд-петлю**: последние ~1–1.5 секунды выбранного отрезка
   плавно перетекают (через blend/dissolve) в первые ~1–1.5 секунды того
   же отрезка.
3. Проверить петлю на большом экране в цикле минимум 3–4 повтора подряд —
   глаз ловит рывки, которые не видны на одном проигрывании.

**Надёжнее и предсказуемее** для этого конкретного случая — не видео-
генерация, а кодовая анимация (CSS/SVG/Lottie) по таблице выше: там петля
гарантированно точная, без монтажных компромиссов, и весит в разы меньше
для сайта.

## Хореография (покадрово, по слоям)

### Слой 1 — Кольца/дуги (символ вечности), фон
- Сверхмедленное вращение по таблице выше. На глаз должно читаться не
  «крутится», а «едва заметно движется, если приглядеться» — как минутная
  стрелка часов.
- Каждое кольцо — своя скорость и своё направление (часть по часовой,
  часть против) — эффект «нескольких слоёв времени», а не одного жёсткого
  диска.
- **Категорически нельзя:** быстрое вращение (даже «средняя» скорость
  превращает символ вечности в игрушку-вертушку — теряется весь смысл).

### Слой 2 — Незабудка (центр)
- **Дыхание**: масштаб 100% → 102% → 100%, период 5с (см. таблицу), easing
  — плавный синус/spring без пружинного перехлёста (`spring(damping:200)`
  из `brand-video.md`, никакого «boing»).
- **Тычинки** (точки на концах): едва заметное мерцание opacity 85%→100%,
  у каждой точки — свой период и свой фазовый сдвиг из таблицы — читается
  как живое подрагивание/внимание к деталям, а не как строб.
- Лепестки не двигаются независимо от общего «дыхания» — цветок остаётся
  одной цельной формой, не «трепещет» по отдельности (выглядело бы
  тревожно/ветрено, а не спокойно).

### Слой 3 — Руки
- **Дыхание опоры**: вертикальное смещение ±2px, период 7.5с — чуть
  медленнее и намеренно не синхронно с дыханием цветка (руки — опора, они
  должны быть чуть более «неподвижны», чем то, что держат).
- Никакого раскрытия/закрытия ладоней, никакого «поднятия рук в кадр» в
  фоновом (idle) состоянии — это уже опора, а не жест.

### Слой 4 — Свет (опционально)
- Раз в 10 секунд — очень мягкий диагональный блик (linear-gradient
  highlight), проходящий через всю эмблему за ~1.5–2 секунды, как утренний
  свет, скользнувший по линиям. Прозрачность ~15–20%, чтобы не выглядеть
  как «глянцевая реклама». Необязательный слой — если инструмент не умеет
  такой блик, просто пропустить.

## Момент появления (если это hero-заставка при загрузке страницы)

Это **отдельная, одноразовая** последовательность — она НЕ часть
бесконечной петли и к требованию бесшовности не относится:

1. Руки — едва заметно «оседают» на место снизу вверх (±10px), 0.6с,
   spring, без отскока.
2. Кольца — **прорисовка линии** (SVG stroke-dasharray/stroke-dashoffset
   «рисование от руки»), 1.2–1.5с, от центра наружу.
3. Незабудка — раскрывается из полу-сомкнутого бутона в полный цветок за
   ~1с, **после** того как кольца дорисовались (не одновременно — должна
   читаться последовательность: сначала время/постоянство, потом то, о
   чём заботятся).
4. Дальше — плавный переход в бесконечный цикл выше, без рывка (кольца
   продолжают вращение с той же угловой позиции, на которой закончилась
   прорисовка).

Общая длительность появления: **~3 секунды**. Дальше — бесшовный 60-
секундный цикл, повторяющийся неограниченно.

## Технические требования

- **Формат:** предпочтительно SVG/CSS-анимация или Lottie — векторное,
  лёгкое, чёткое на любом экране, прозрачный фон, гарантированно точная
  петля (см. таблицу выше). Если всё же нужен рендер видео — WebM с
  альфа-каналом или MP4, с петлёй через кроссфейд-монтаж (см. раздел про
  AI-видео выше).
- **Длительность петли:** ровно 60 секунд.
- **Частота:** 30 fps достаточно (движение медленное, рывков не будет).
- **`prefers-reduced-motion`:** обязательно уважать — статичный вариант
  (например, только тихое мерцание тычинок, без вращения и без дыхания)
  для пользователей с этой настройкой.
- **Цвета:** без изменений — оливковый `#5E6A3A`/`#7C8654`, светлый
  антрацит `#33373C`/`#6B7075`, серые тона колец, тёплый белый `#FAFAF7`.
  Никаких новых цветов, никакого неонового свечения/drop-shadow.

## Слова-ориентиры (для AI-инструмента, если генерация текстовым промптом)

«seamless perfect loop», «tending», «quiet continuity», «breathing, not
spinning», «a caretaker's patience», «barely-there motion», «morning light
passing over line art», «heartbeat-slow», «dignified, not decorative».

## Что нельзя (ломает смысл или петлю)

- Быстрое или заметное вращение колец — превращает вечность в
  «вертушку»/игрушку.
- Любой период движения, который не делит 60 секунд нацело — петля не
  сойдётся, будет виден рывок на стыке.
- Пружинный «boing»-отскок на дыхании цветка/рук — это не весёлая
  анимация, это уход.
- Мигание/строб тычинок в унисон (без фазового сдвига) — читается как
  ошибка/глюк, а не как «живой огонёк внимания».
- Частицы, конфетти, вспышки, блеск/сияние поверх цветка — про уход, не
  про праздник.
- Звук по умолчанию (autoplay с аудио).
- Любое изменение геометрии эмблемы «в процессе» анимации (лепестки не
  меняют форму, руки не меняют форму ладони, кольца не меняют толщину) —
  только положение/масштаб/прозрачность/вращение целиком.

## Готовый CSS-каркас (кольца, точные периоды из таблицы — петля гарантированно бесшовная)

```css
/* Каждое кольцо — своя длительность и направление, все делят 60с нацело */
.mc-ring-a { animation: mc-spin-cw 60s linear infinite; transform-origin: center; }
.mc-ring-b { animation: mc-spin-ccw 30s linear infinite; transform-origin: center; }
.mc-ring-c { animation: mc-spin-cw 20s linear infinite; transform-origin: center; }
.mc-ring-d { animation: mc-spin-ccw 60s linear infinite; animation-delay: -15s; transform-origin: center; }
.mc-ring-e { animation: mc-spin-cw 15s linear infinite; transform-origin: center; }

@keyframes mc-spin-cw  { from { transform: rotate(0deg); } to { transform: rotate(360deg); } }
@keyframes mc-spin-ccw { from { transform: rotate(0deg); } to { transform: rotate(-360deg); } }

@keyframes mc-flower-breathe {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.02); }
}
.mc-flower-group {
  animation: mc-flower-breathe 5s ease-in-out infinite;
  transform-origin: center;
}

@keyframes mc-hands-breathe {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-2px); }
}
.mc-hands-group { animation: mc-hands-breathe 7.5s ease-in-out infinite; }

@keyframes mc-stamen-flicker {
  0%, 100% { opacity: 0.85; }
  50%      { opacity: 1; }
}
.mc-stamen-dot:nth-child(1) { animation: mc-stamen-flicker 4s   ease-in-out infinite; }
.mc-stamen-dot:nth-child(2) { animation: mc-stamen-flicker 5s   ease-in-out infinite -1.2s; }
.mc-stamen-dot:nth-child(3) { animation: mc-stamen-flicker 6s   ease-in-out infinite -2.7s; }
.mc-stamen-dot:nth-child(4) { animation: mc-stamen-flicker 7.5s ease-in-out infinite -0.6s; }
/* ...остальные точки: любой из периодов 4s/5s/6s/7.5s/10s, с любым сдвигом */

@media (prefers-reduced-motion: reduce) {
  .mc-ring-a, .mc-ring-b, .mc-ring-c, .mc-ring-d, .mc-ring-e,
  .mc-flower-group, .mc-hands-group, .mc-stamen-dot { animation: none; }
}
```
