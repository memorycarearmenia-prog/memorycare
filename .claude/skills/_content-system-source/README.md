# Контент-система Георгия Риверы

10 скиллов для Claude AI, которые передают работу друг другу по цепочке:

`Идея → Фокус → Производство → Чистка → Монетизация`

| # | Скилл | Команда | Что делает |
|---|---|---|---|
| 1 | Директор | `/director` | Держит одну цель, отсекает контент ради контента |
| 2 | Разведчик | `/scout` | Темы из новостей, личного опыта и вопросов аудитории |
| 3 | Архитектор | `/youtube-pro` | Идеи под поиск, структура видео, заголовок + превью |
| 4 | Хук-мастер | `/hook` | Открытие от кульминации, чистка хук-артефактов |
| 5 | Сценарист | `/reels` | Полный сценарий короткого видео в твоём голосе |
| 6 | Мультипликатор | `/multiply` | Одно длинное → 10 коротких, серия, развитие успеха |
| 7 | Дистрибьютор | `/posts` | Подписи с CTA под площадку + рассылки |
| 8 | Антидетектор | `/antidetector` | 52 паттерна: убирает следы ИИ, возвращает голос |
| 9 | Магнит | `/lead-magnet` | Конкретные лид-магниты под твой опыт |
| 10 | Кузнец | `/skill-forge` | Куёт твои собственные скиллы |

## Установка

Один файл — вся система. Открой **Cowork** (именно Cowork, не чат) → **Customize** (чемоданчик слева) → раздел **Plugins** → **＋** → «Загрузить свой плагин» — и перетащи этот файл в окно. Все 10 скиллов появятся сразу.

## Сначала — брендбук

Половина звеньев читает «голос бренда». Возьми `brandbook-template.md` из этого плагина, заполни под себя (10 минут) и положи в свой проект Claude. Без брендбука скиллы пишут как «умный человек», с ним — твоим голосом.

## Как вызвать

В Cowork или в чате набери `/` и имя скилла. Типовой маршрут:
`/scout` → `/hook` → `/reels` → `/posts` → `/antidetector`.
На входе всё сверяй `/director`, на выходе — `/lead-magnet`.
