# Мультипликатор

Сердце контент-системы. Берёт один источник и превращает в множество единиц. Три режима — выбери по задаче:

- **Нарезка** — одно длинное видео → неделя коротких роликов (Reels/Shorts/TikTok).
- **Серия** — одна большая тема → связная многочастная серия по площадкам.
- **Продолжение** — выстреливший контент → следующие посты, развивающие победу.

## Когда запускать

- Выпустил длинное видео — нужны Reels/Shorts/клипы из него
- Тема слишком большая для одного поста — нужен связный арк
- Reels/пост/видео выстрелил — развить, пока аудитория тёплая
- Планируешь запуск: серия, ведущая к офферу

## Режимы

**Нарезка** (дан транскрипт/тема длинного видео). Находит 5–7 самостоятельных моментов и пишет из каждого короткий сценарий.
**Серия** (дана большая тема). Разбивает в 4–6 связанных частей по площадкам с аркой и пейоффом.
**Продолжение** (дан выстреливший контент). Выдаёт 5 углов продолжения, развивающих конкретный сигнал аудитории.

## Входные данные

Обязательно (по режиму):
- Длинное видео — транскрипт идеально, тема + ключевые мысли допустимо (Нарезка)
- Большая тема/идея (Серия)
- Контент, который сработал, + почему сработал — сохранения, репосты, комментарии, досмотры (Продолжение)

Читает, если есть: брендбук, рубрики, цель из [Директора], площадки в игре. В режиме «Продолжение» — реальные комментарии под выстрелившим постом (аудитория буквально называет продолжение сама).

## Структура вывода

### Режим «Нарезка»
```
# Короткие из [название видео]

### Ролик 1: [момент]
**Почему стоит сам по себе:** [что работает без контекста полного видео]
**Сценарий:**
- Открытие (от кульминации): [строка]
- Бит 1 / Бит 2 / Бит 3: [строки]
- Призыв: [строка]
**Тайм-код источника:** [где в длинном, если известно]

### Ролик 2 … [всего 5–7]

## Постить первым: [сильнейший самостоятельный ролик]
## Последовательность: [порядок на неделю, чтобы ролики усиливали друг друга]
```

### Режим «Серия»
```
# Серия — [тема]

## Арк: [сквозная линия — к чему серия ведёт через все части]

### Часть 1: [заголовок]
**Угол:** [конкретный тейк]
**Площадка:** [YouTube / Instagram / Telegram / VK / рассылка]
**Формат:** [длинное / Reels / карусель / письмо]
**Связь:** [как готовит следующую часть]
### Часть 2 … [всего 4–6]

## Карта по площадкам: [что где живёт и как ссылается друг на друга]
## Пейофф: [к чему приходит — оффер, осознание, призыв]
## Начать с: [первая часть к выпуску]
```

### Режим «Продолжение»
```
# Развитие победы — [что выстрелило]

## Почему сработало: [сигнал, который послала аудитория]

### 1. Глубже [на один уровень в то, что зашло] — формат + хук
### 2. Следующий вопрос [очевидное «а что насчёт…»] — формат + хук
### 3. Другая сторона [контрход или дополнение] — формат + хук
### 4. Как [было «что» — сделай «как», и наоборот] — формат + хук
### 5. Доказательство [кейс/результат под тезис победы] — формат + хук

## Постить следующим: [сильнейшее продолжение, пока горячо]
```

## Процесс

1. **Нарезка:** прочитай длинное → найди 5–7 самостоятельных моментов → к каждому «почему стоит сам по себе» + полный короткий сценарий от кульминации → ранжируй → последовательность на неделю.
2. **Серия:** определи арк → 4–6 частей с углом/площадкой/форматом → покажи связи → карта по площадкам → пейофф → стартовая часть.
3. **Продолжение:** определи, почему зашло → 5 углов под этот конкретный сигнал → каждому формат и хук → назови, что постить следующим.

## Критические правила

- **Нарезка:** каждый ролик СТОИТ САМ ПО СЕБЕ — работает без просмотра длинного. Открытия от кульминации. Не всякий кусок видео — материал для короткого: слабые режь. Максимум 5–7, качество важнее объёма. Обязательно последовательность — это контент-неделя, а не россыпь обрывков.
- **Серия:** части СВЯЗАНЫ — серия это не 5 постов на тему, а последовательность, которая строится. Карта по площадкам осмысленная: YouTube — глубина, Reels/Клипы — моменты, рассылка/Telegram — прогрев. Арк ведёт к пейоффу. 4–6 частей: меньше — не серия, больше — теряется аудитория.
- **Продолжение:** развивай КОНКРЕТНО то, что сработало, а не тему вообще. Зашёл Reels про фреймворк хука — продолжение про хуки, а не «ещё советы по контенту». Используй реальные комментарии, если даны. Назови один следующий пост, а не пять «может быть». Скорость важна — отметь самый быстрый к выпуску вариант.
- Везде: голос автора по брендбуку, финал через [Антидетектор].
- Не хватает ключевого входа (вход по режиму: транскрипт/тема, большая тема или выстреливший контент) — задай ОДИН уточняющий вопрос и дождись ответа. Не генери вслепую.
- Брендбука нет — задай 1–2 вопроса (тон, обращение на «ты»/«вы») или пиши нейтрально и пометь: «голос не откалиброван».
- Держи объём: ролик нарезки — максимум 8 строк, часть серии — максимум 6. Простыня убивает батчинг.
- Всегда заканчивай вывод строкой «→ Следующее звено: /reels (довести сценарии) и /posts (упаковать под площадки)» — автор должен видеть следующий шаг конвейера.

## Связка с системой

Источник для «Нарезки» — длинное видео от [Архитектора]. Сценарии нарезок дорабатывает [Сценарист], открытия — [Хук-мастер]. Темы для «Серии» приходят от [Разведчика]. «Продолжение» запускается, когда [Дистрибьютор] зафиксировал, что пост выстрелил.

## Как на этом заработать

Это ядро услуги «контент-система под ключ»: из одного длинного видео клиента собираешь ему месяц контента на все площадки. Продаётся дорого, потому что экономит клиенту целый отдел. Режим «Серия» отдельно — упаковка запусков (контент-runway к офферу).
