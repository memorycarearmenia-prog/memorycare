# Брендбук / паспорт голоса

Это шаблон, который читают все звенья контент-системы Георгия Риверы
(Директор, Разведчик, Архитектор, Хук-мастер, Сценарист, Мультипликатор,
Дистрибьютор, Антидетектор, Магнит, Кузнец), чтобы писать голосом автора,
а не нейтральным «умным человеком».

Живёт в этом репозитории (`.claude/skills/brandbook/`), поэтому виден в
любой сессии, открытой в проекте memorycare.

Для MemoryCare голос/тон/аудитория/цель уже описаны в `/CLAUDE.md`
(и синхронизированы с `docs/BUSINESS-CONTEXT.md`, `docs/site-update-prompt.md`)
— **при работе над контентом MemoryCare бери факты оттуда, а не выдумывай
заново**: тон премиальный/тёплый/достойный, аудитория — диаспора и локальный
premium-сегмент Еревана поровну, слоган «The care that matters» / «Խնամքը,
որը կարևոր է» и т.д. Этот файл — генерический шаблон на случай, если
скиллы контент-системы понадобятся для другого бренда/проекта или если
кому-то нужен именно формат «паспорт голоса» из карточки ниже.

## Как этим пользоваться

- Если пользователь просит показать шаблон — верни раздел «Шаблон» ниже как есть.
- Если пользователь просит завести/заполнить брендбук для MemoryCare — не
  дублируй факты вручную, а собери карточку из `CLAUDE.md` и
  `docs/BUSINESS-CONTEXT.md` и сверь несостыковки, прежде чем отдавать.
- Если пользователь просит завести/заполнить брендбук для другого проекта —
  собери ответы на все 7 пунктов (спрашивай по одному блоку, не всё сразу).
- Если другой скилл контент-системы ищет брендбук и не находит заполненную
  версию — работай по правилу этих скиллов: «пиши нейтрально и пометь: голос
  не откалиброван» или задай 1–2 уточняющих вопроса (тон, обращение на
  «ты»/«вы»).
- Не выдумывай ответы на пункты шаблона от имени пользователя — если поле
  не заполнено и не спрошено, оставляй его пустым.

## Шаблон

## 1. Кто я
- Имя / бренд:
- Чем занимаюсь (одно предложение):
- Опыт и регалии (что даёт право говорить на тему):
- Ниша и темы (рубрики), о которых делаю контент:

## 2. Цель (её читает Директор)
- Главная цель сейчас (одна): [деньги / рост аудитории / качество аудитории / лиды / авторитет]
- Метрика и срок: [например: 300 заявок в воронку за квартал]
- Что продаю (услуга / продукт / консалтинг):

## 3. Аудитория
- Кто эти люди (возраст, род занятий, ситуация):
- Их боли и задачи (своими словами, как говорят сами):
- Чего хотят достичь:
- Как моя тема/услуга решает их боль:

## 4. Голос бренда
- Тон: [дружеский / экспертный / провокационный / наставнический / ироничный — выбери 1–2]
- Формальность (1–10):
- Обращение к аудитории: [на «ты» / на «вы»]
- Фирменные обороты и слова (что я говорю часто):
- Любимые частицы и приёмы (ведь, вот, же; ирония; короткие рубленые фразы; вопросы):
- Подпись / прощание (точная формулировка, например: «Побеждайте любя»):

## 5. Стоп-лист
- Слова и фразы, которые НЕ использую никогда:
- Эмодзи: [да / нет / умеренно]
- Темы, которых не касаюсь:

## 6. Площадки
- Где публикуюсь: [YouTube / RuTube / VK Видео / Telegram / VK / Instagram / Дзен / VC / MAX]
- Главная площадка:
- Кодовое слово / воронка (ChatPlace), если есть:

## 7. Примеры моих текстов
Вставь 2–3 своих поста, сценария или куска расшифровки видео — по ним скиллы снимут твой настоящий ритм и лексику. Это самое важное поле: один реальный пример точнее десяти строк описания.

```
[твой текст 1]
```
```
[твой текст 2]
```

## Критические правила

- Для MemoryCare источник истины — `CLAUDE.md` и `docs/BUSINESS-CONTEXT.md`, не этот шаблон. Не переписывай сюда бренд-факты MemoryCare — сверяйся с ними напрямую.
- Один заполненный брендбук = один проект/бренд. Для второго проекта — отдельная заполненная копия, не перезапись этого общего шаблона.
- Не подменяй факты пользователя своими предположениями — не знаешь ответ на пункт, оставь пустым или спроси.
