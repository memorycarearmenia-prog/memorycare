# MONTEC — что исправить в редизайне сайта

Рабочий бриф по итогам разбора версии «Website redesign with theme options»
(файл `Montec Site.dc.html`, 721 строка, + каталог `_ds/` и `assets/`).
Разбор проведён 11.08.2026 семью ролями: UI/UX-дизайнер, контент-менеджер,
фронтенд-инженер, владелец бизнеса, бренд-гардиан и два покупателя (диаспора
и корпоративный клиент). Все номера строк — по этому файлу.

**Как пользоваться документом.** Его можно отдать целиком как задание. Раздел 1 —
то, без чего сайт нельзя показывать никому. Раздел 2 — жёсткие факты бренда,
их нельзя менять по своему усмотрению. Разделы 3–9 — исправления по темам.
Раздел 10 — порядок работ.

**Что в этом файле — правда по определению.** Источник истины по бренду, продукту
и ценам — `montec/CLAUDE.md` в репозитории. Если любой файл, макет или текст
противоречит ему, прав `CLAUDE.md`, а расхождение надо назвать вслух, а не
«починить» на своё усмотрение.

## 1. Блокеры — исправить прежде всего остального

### 1.1. Из поставки убрать каталог `_ds/` целиком

`_ds/montec-design-system-<uuid>/readme.md` — внутренний бриф на 162 строки,
лежащий рядом с сайтом как обычный статический файл. При заливке папки на хостинг
он открывается по прямой ссылке. В нём:

- полная таблица цен в AMD по всем 13 SKU;
- «The Access — corporate edition · 17 500 / unit (modeled)» — расчётная
  цена корпоративной программы за единицу;
- «Launch is asset-light on **$5 000**» — бюджет запуска;
- «It localises the **Von Baer** DTC playbook» — Von Baer это внутренняя
  исследовательская модель, её нельзя упоминать в связке с брендом;
- «prior leather production: Montec and **Bagrat's Bags**» — бюджетный сестринский
  бренд, который нельзя смешивать с MONTEC;
- «a **live** 500-unit engraved card-holder programme» — это Nairi Insurance,
  программа реальна, но **на паузе**, и живой её называть нельзя;
- 3 ссылки на Google Docs/Sheets (в т.ч. финмодель) и 2 на папки Google Drive;
- имя основателя и поставщик фурнитуры, которых нет в каноне.

**Как исправить:** каталог `_ds/` не должен попадать ни в один деплой. Токены
и компоненты подключать сборкой, а не копированием папки с документацией.
Отдельно проверить, не открыт ли сам проект в Claude Design по ссылке, доступной
третьим лицам.

### 1.2. Форма заявки уничтожает обращение и благодарит за него

Строка 714:

```js
submit: () => { this.setState({ sent: true }); window.scrollTo({ top: 0 }); },
```

Никакой отправки, никакого хранения. Следом показывается «Your request is with
the house. We reply within two working days». Ни одна заявка не дойдёт, и вы
об этом не узнаете, потому что ошибки не происходит.

Дополнительно:
- элемента `<form>` нет вообще — поля стоят по отдельности, у них нет атрибута
  `name`, поэтому перехватить отправку нечем и без JS форма не работает;
- флаг `sent` нигде не сбрасывается: после первой заявки экран «Получено»
  становится постоянным до перезагрузки страницы;
- список выбранных предметов (главный смысл механики) в отправку не собирается.

**Как исправить:**
1. Обернуть поля в `<form name="montec-access" method="POST" data-netlify="true"
   data-netlify-honeypot="company-website">`, каждому полю дать `name`.
2. В тело письма класть: выбранные предметы, язык интерфейса, город, страницу,
   с которой пришла заявка.
3. Сбрасывать `sent`, `form`, `consent`, `list` при уходе с экрана заявки.
4. Сделать состояния «отправляется» и «не отправилось, напишите нам на …».
5. Автоответ с адреса живого человека.

### 1.3. Мобильной вёрстки не существует

В файле **ноль правил `@media`** — и в самом файле, и во всей дизайн-системе.
Двенадцать сеток заданы жёстко: hero `1.05fr .95fr` (строка 67), товар
`1.15fr .85fr` (200), реестр `72px 1.1fr 1fr` (244/246), заявка `.9fr 1.1fr`
(342), подвал `1.2fr 1fr 1fr` (417). Шапка высотой 72 px (строка 44) с семью
пунктами меню, переключателем языка и кнопкой не помещается.

Что видит человек на телефоне 390 px: пункты меню напечатаны поверх заголовка
«Quiet is the loudest luxury»; заголовок в 72 px (не `clamp`) ломается на четыре
строки; «The Founder» рендерится шириной около 45 px; карточки «Кодекса»
срезаются краем экрана; по меню нельзя ткнуть — переход на карточку товара
не срабатывает.

**Как исправить.** Одна точка перелома, полдня работы:

```css
@media (max-width: 900px) {
  /* все двухколоночные сетки — в одну колонку */
  /* шапка: height:auto; min-height:64px; меню — в шторку по одной кнопке */
  /* h1: clamp(38px, 9vw, 72px) */
  /* герой: изображение на всю ширину над текстом */
}
```

Стили сейчас живут в инлайновых `style`, а туда медиазапрос не поставить, —
значит нужен настоящий CSS-класс хотя бы для сеток, шапки и заголовков.
**Диаспора — это в основном телефон; до этого исправления весь мобильный трафик
теряется целиком.**

### 1.4. Цены уехали в исходный код

Строка 444: `const PRICES = [270000,230000,190000,null,40000,40000,40000,30000,30000,null,null,null,null];`
плюс `AMD()` (441), `priceLabel` (647), `piecePriceLabel` (693), `poa` (488/541/594),
`stat3: 'Per unit, indicative'` (503).

На экране цены нет — а в «просмотре кода», в архиве страницы и в любом парсере
она есть, по каждому предмету, в валюте котировки. Заодно видно, какие пять
предметов вы пока не можете оценить.

**Как исправить:** удалить `PRICES`, `AMD()`, `priceLabel`, `piecePriceLabel`,
`poa`, `stat3` из клиента полностью. Решение «цен на сайте нет» должно быть
структурным: цены живут в финмодели и в ответе на заявку, а не в браузере.

### 1.5. У страницы нет `<head>`

В документе только кодировка, viewport и скрипт. Нет `<title>`, описания,
canonical, `og:*`, `twitter:*`, фавикона, разметки для поисковиков. Тело
документа скрыто до загрузки React (`x-dc{display:none!important}`).

Bing, WhatsApp, Telegram, LinkedIn, Slack, iMessage и ИИ-краулеры JavaScript
не исполняют — они получают пустой документ без имени. Ссылка на сайт,
отправленная клиенту в мессенджере, выглядит как голый адрес.

**Как исправить:** изнутри одностраничного приложения это не чинится — нужен
пререндер. См. п. 10.

### 1.6. Один адрес на весь сайт

`go(view)` (строка 637) меняет состояние компонента и не трогает URL. Ни одного
`<a href>` во всём сайте, кроме двух ссылок на соцсети (431–432).

Следствия: нельзя прислать клиенту ссылку на «The Founder»; нельзя вести рекламу
на корпоративную страницу; кнопка «назад» уводит с сайта из любой глубины;
обновление страницы возвращает на главную; язык хранится только в браузере,
поэтому русскоязычному клиенту нельзя отправить русскую версию; аналитика видит
один просмотр на сессию.

**Как исправить:** настоящие адреса на каждую страницу и на каждый SKU, в каждом
языке. `history.pushState` + `popstate` и `<a href>` — минимум; правильно —
пререндер (п. 10).

### 1.7. Связаться с домом нечем

Ни почты, ни телефона, ни WhatsApp, ни адреса, ни юрлица. Домены в подвале
(`themontec.com · montec.am`) — просто текст, даже не ссылки.

**Как исправить:** имя человека, почта на домене, WhatsApp Business (подтверждённый
канал MONTEC), юрлицо (FiCorp) в подвале. Отдельная почта и отдельная форма для
корпоративных обращений. Заявку на закупку нельзя оформить «на сайт».

## 2. Канон бренда — менять нельзя

### 2.1. THE AUDIT: пять полей, не четыре

Сейчас на карточке четыре строки (`specLeather / specHardware / specMade / specMark`,
значения 490–493), и **все значения — глобальные константы**: «The Founder»
и «The Standard» показывают побайтово одинаковую спецификацию.

Канонические поля, в этом порядке, на всех тринадцати карточках:

| Поле | Что в нём |
|---|---|
| **EXTERNAL** | сорт кожи |
| **ARCHITECTURE** | конструкция, устройство |
| **VOLUME** | вместимость, сценарий использования |
| **HARDWARE** | материал и отделка фурнитуры |
| **MARKINGS** | брендирование, тиснение |

**Как исправить:** вернуть все пять полей с реальным текстом **по каждому SKU** —
он уже написан и лежит в `montec/site/lib/products.ts`. Добавить размеры в
сантиметрах и вес. Когда цены нет, спецификация — единственное, что покупатель
может оценить; сейчас на сайте нет ни одного размера ни у одного предмета.

Две фактические ошибки, которые исчезнут вместе с этим: ремни и настольный мат
сейчас описаны как кожа **с латунной фурнитурой**, а THE CAPITAL и THE ACCESS
по канону сделаны **вообще без видимого металла**.

Поле «Made» (происхождение) — хорошая идея, но только **шестым** полем и только
после того, как место производства подтверждено (см. 3.1).

### 2.2. Old-Money Code: шесть правил, не пять

Сейчас — «The terms of the house. Five clauses». Четыре правила переписаны,
два выброшены, одно придумано.

Канонические шесть:

1. **No logos, loud** — «The mark is a whisper, never a billboard. Recognition
   is for insiders, not passers-by.»
2. **No discounts, ever** — «The price is the price. A markdown is a confession
   that the first price was a lie.»
3. **By application** — «You are admitted, not sold to.»
4. **Numbered batches** — «Limited, dated, finite.»
5. **Material honesty** — «Full-grain, vegetable-tanned. Nothing corrected,
   nothing hidden.» ← **выброшено, вернуть**
6. **Made at home** — «Italian leather, Armenian hands.» ← **выброшено, вернуть**
   (но см. 3.1 — формулировку про место производства придётся смягчить)

Придуманное правило **«Repaired, not replaced»** — не канон и обещает политику,
которой нет. См. 3.2.

### 2.3. Порядок и номера SKU

Восемь из тринадцати предметов получили чужие номера. Номер уходит слепым
тиснением внутрь изделия — ошибка дорогая.

Канонический порядок:

| № | Предмет | Объект | Группа |
|---|---|---|---|
| 01 | The Founder | Weekender | Carry |
| 02 | The Executive | Briefcase | Carry |
| 03 | The Unit | Laptop module | Carry |
| 04 | The Closer | Messenger bag | Carry |
| 05 | The Arena | Desk mat | Command center |
| 06 | The Brief | Men's clutch | Command center |
| 07 | The Capital | Bifold wallet | Financial |
| 08 | The Treasury | Long wallet | Financial |
| 09 | The Access | Cardholder | Financial |
| 10 | The Voyager | Dopp kit | Lifestyle |
| 11 | The Vision | Glasses case | Lifestyle |
| 12 | The Backbone | Belt · brown | Foundation |
| 13 | The Standard | Belt · black | Foundation |

Также:
- **Группы — пять, а не четыре.** Сейчас Lifestyle растворён, Command center
  сжат до «Desk (1)». Вернуть: Carry / Command center / Financial / Lifestyle /
  Foundation.
- **Формат хлебных крошек**: `01 / 13 — WEEKENDER` (двузначный номер, знаменатель,
  категория). Сейчас `BATCH 001 · NO. 001` — без знаменателя и без категории.
- Утверждение «numbered in the order they were **designed**» каноном не
  подтверждено — либо убрать «designed», либо заменить на нейтральное
  «numbered in the order of the batch».

### 2.4. Цвет

Канон: **Obsidian `#0A0A0A`**, **Brass `#B8975A`** (мягкий вариант `#C9AE7C`),
**Anthracite `#2B2B2B`** (глубокий `#3A3A3A`), **Warm Paper `#FAF8F3`**.
Соотношение: обсидиан 70 % / антрацит-бумага 24 % / латунь 6 % — «латунь это
приправа, а не соус».

Две проблемы:
1. **Значения разъехались**: в токенах `--montec-obsidian:#141210` и
   `--montec-anthracite:#322D28`. Вернуть к каноническим.
2. **Соотношение перевёрнуто**: бумага занимает около 90 %, обсидиан остался
   только в тексте. Сами цвета при этом канонические — нарушено соотношение
   и роли, а не палитра.

**Как исправить.** Светлая земля — вопрос к владельцу, не к исполнителю
(см. 9.2). Инженерно: перестать копировать роли цветов вручную в `body`
(строки 15–24) и подключить готовый класс `.montec-on-paper` из токенов.
Тогда исчезнет чёрная тень на светлой панели, а переключатель тем (ключи
`paper` / `obsidian` уже переведены на все три языка и не подключены ни к чему)
станет одним булевым значением.

### 2.5. Типографика

- **Cormorant Garamond** — заголовки, названия предметов, словесный знак,
  выносные цитаты. **Inter** — текст, подписи, интерфейс, спецификации.
- Никогда: текст абзацами в засечном; название предмета в гротеске.
  Сейчас лиды (строки 167, 235, 275, 297) набраны засечным 22 px — это не
  выносная цитата, а бегущий текст. Перевести в Inter.
- **Армянский** сейчас набирается не тем шрифтом: армянские начертания
  подключаются по атрибуту `data-lang`, а код выставляет только `lang`.
  Исправление в одну строку (628/638):

```js
document.documentElement.dataset.lang = l;
```

  Без этого армянский идёт случайным системным шрифтом (в Cormorant Garamond
  армянских глифов нет вовсе) и сохраняет латинский межбуквенный интервал
  `.28em`, который армянские формы разрушает.
- Компаньоны для армянского: **Noto Serif Armenian** (к Cormorant) и
  **Noto Sans Armenian** (к Inter).

### 2.6. Логотип

- Минимальная ширина лока — **120 px**. Сейчас 81 px в шапке (строка 46)
  и 108 px в подвале (419). Увеличить.
- `assets/logo/mark.png` **побайтово совпадает** с локом — отдельного знака
  в поставке нет. Нужен настоящий одиночный монограмм для фавикона и мелких
  применений.
- `src-lockup.png` — это JPEG с расширением `.png`.
- Логотип — плоский двухцветный знак, отданный растром на 30 КБ. Нужен SVG.
- Размеры по спецификации: знак S 15 мм, лок M 45 мм, лок L 70 мм, строка
  ORIGIN 3,5–4 мм.

### 2.7. Слоганы и CTA

- **Ни одного канонического слогана нет на сайте**, ни на одном языке.
  Вернуть хотя бы один в точной формулировке:
  «Craftsmanship and strategy for those who write history» — строка о клиенте;
  «I am not rich enough to buy cheap things» — строка о предмете.
- **CTA канона — `REQUEST ACCESS`.** Сейчас четыре названия одного действия:
  «Request», «Request this piece», «Add to request», «Apply for a piece».
  Оставить одно имя от кнопки до подтверждения. На карточке товара — именно
  `REQUEST ACCESS`.

### 2.8. Материал

Канон: **full-grain, vegetable-tanned Italian leather** + **solid Italian brass**.

Сейчас на сайте везде «Italian **calfskin**» (телячья кожа) — более узкое
и более дорогое утверждение о сырье, чем бизнес подтверждал, на том самом
свойстве, которым оправдана цена. Причём русская и армянская версии говорят
просто «итальянская кожа» / «իտալական կաշի» — сайт противоречит сам себе.

**Как исправить:** везде «Italian leather». (В основной сборке сайта эта же
ошибка уже исправлена 11.08.2026.)

## 3. Утверждения, которых бизнес не принимал

Каждое из них — обязательство перед покупателем. Либо решение принимается
и фиксируется в `CLAUDE.md`, либо строка удаляется. Ранжировано по риску.

### 3.1. Место производства

Строки: «Cut and finished in Yerevan» (спецификация, 492), «Everything is cut,
stitched, burnished and boxed in Yerevan» (464), «Origin — handcrafted in Armenia»
(подвал, 511 — на всех 25 экранах).

В каноне место производства (Армения / Италия / иное) **не зафиксировано**;
подтверждено только «designed in Armenia». Это ровно тот факт, который
корпоративный клиент просит подтвердить письменно, а комплаенс банка — до начала
программы.

**Как исправить:** либо владелец фиксирует место производства, либо формулировка
смягчается до подтверждённого: «Designed in Armenia. Italian hides, Italian brass.»

### 3.2. Ремонт — самое дорогое обещание на сайте

«Repaired, not replaced. Brass is re-set, stitching re-run, edges burnished again
— in Yerevan, by the hands that made it» (499) + карточка на главной (479).

Ни срока, ни географии, ни исключений. Формулировка «the piece returns to you,
not to a warehouse» подразумевает, что логистику берёте вы. Мастера получают
оплату за заказ — ремонт это заказ, за который никто не платит, плюс две стороны
международной доставки. Одна трансатлантическая починка может съесть маржу
с продажи.

**Как исправить:** до решения — убрать. При решении — ограничить: срок в годах,
исключён естественный износ, входящая доставка за счёт клиента, приём в Ереване.

### 3.3. Доставка

«Ships from Yerevan · international post to the diaspora» (470).

Две проблемы. Первая: политика доставки и возвратов не написана — нет
перевозчика, трекинга, страховки, позиции по пошлинам и пути возврата для сумки
за 270 000 ֏ через границу. Вторая: формулировка «диаспоре» **сужает экспортный
рынок** — любой не-армянский международный покупатель читает, что доставка
не для него. Это ровно та ошибка исключающего адреса, на которой проект уже
однажды поправляли.

**Как исправить:** «Delivered worldwide from Yerevan» + отдельная страница
с доставкой и возвратом. Простой возврат — названная слабость Von Baer, обыграть
её дёшево, но только если политика написана.

### 3.4. Корпоративные цифры

- «Programmes start at fifty units» / «50+ minimum programme» (480, 502–503, 332 —
  «50+» вообще зашито в инлайновый стиль). Порог не подтверждён и, скорее всего,
  вредит: первый реальный корпоративный заказ — это 20 предметов для правления,
  и именно он даёт вам первый референс. Заменить на «typically begin around fifty
  units» или убрать число.
- «Emboss die to delivery — 4 weeks» (503). Срок указан так, будто он не зависит
  от тиража. Четыре недели на 50 и на 400 не могут быть правдой одновременно.

- «Per unit, indicative» (`stat3`, 503) — переведено на три языка и не выводится.

## 4. Вёрстка, сетка, изображения

- **Номер «NO. 0XX» стоит внутри блока изображения** (`position:absolute`, 181),
  поэтому по близости читается как подпись к предыдущей карточке: до соседней
  карточки 48 px, до своего же товара ~100 px. Вынести номер в подпись, над
  названием.
- **Масштаб предметов уничтожен.** Каждый вырез растянут под общий холст:
  настольный мат 60 см, чехол для ноутбука и сложенный бифолд занимают в сетке
  одинаковое место. Пересобрать вырезы в едином физическом масштабе (постоянное
  число миллиметров на пиксель): ремень длинный, картхолдер маленький.
- **`the-voyager-front-cut.png` вырезан с браком** — остаток студийного фона
  доходит до всех четырёх краёв холста (alpha-bbox `0,0,341,306` против
  `27,51,312,277` у «The Founder») и на светлой подложке читается серой рамкой.
  У `the-access-front-cut.png` то же по правому и нижнему краю. Перерезать оба
  и добавить в конвейер проверку края альфа-канала: на тёмной земле такой брак
  не виден, на светлой виден сразу.
- **Изображения растянуты.** Все вырезы 341×306 px, показываются шириной
  до 600 px — двух-трёхкратное увеличение на сетчатке у бренда, чья идея
  в том, что видно зерно кожи. Нужны исходники крупнее.
- **Формат.** 26 подключённых вырезов в PNG весят 2,13 МБ; те же кадры в WebP
  лежат в архиве неподключёнными и весят 8–10 КБ каждый. Переключить —
  минус ~90 % веса страницы коллекции.
- У изображений на первом экране и на карточке нет `width`/`height` — контент
  прыгает при загрузке. Нет `loading="lazy"` — все 26 картинок грузятся сразу.
- **Карточка товара существует в двух версиях**: на главной 4:3 без номера
  и без действия, в коллекции 1:1 с номером и действием. Свести к одной.
- **Первый экран грузит 3,1 МБ компилятора со стороннего CDN** и компилирует
  код в браузере при каждом визите; шрифты тянутся с Google Fonts (все четыре

  роуминг — 10–15 секунд белого экрана. Если CDN недоступен (сбой, корпоративный
  прокси, фильтрация в РФ — Россия и диаспора у вас в целевых рынках), страница
  остаётся пустой навсегда, без сообщения об ошибке. Решается сборкой (п. 10);
  шрифты — self-hosted, они уже лежат в основной сборке.

## 5. Доступность и ремесло взаимодействия

- **Клавиатурой пользоваться нельзя.** Меню (50), переключатель языка (56),
  кнопка заявки (59), фильтры (171), карточки и «добавить в заявку» (178/185/189),
  переключатель ракурсов (204), строки реестра (246), закрытие панели (390),
  ссылки подвала (424–427) — это `span`/`div` с обработчиком клика: без фокуса,
  без роли, без реакции на Enter. **Заменить на `<a href>` для переходов
  и `<button>` для действий** — это же решает и проблему адресов (1.6).
  В дизайн-системе есть компоненты, которые делают это правильно; страница
  переписала их вручную и потеряла.
- **Галочку согласия нельзя поставить с клавиатуры**: это не `<input
  type="checkbox">`, а два `span` внутри `label`. А без неё кнопка отправки
  заблокирована — пользователь клавиатуры доходит до конца формы и упирается
  в стену. Это одновременно и дефект доступности, и дефект конверсии.
- **У полей формы нет связи с подписью** (`label` без `htmlFor`, `input` без
  `id`), нет `type="email"` и `autocomplete` — на телефоне открывается обычная
  клавиатура и не работает автозаполнение. Рамка поля — контраст 1,84:1, при
  норме 3:1; фокус показан только сменой цвета рамки.
- **Нет видимого состояния фокуса** нигде: `:focus-visible` в файле не
  встречается ни разу. Добавить 2 px латунной рамки со смещением 2 px.
- **Область нажатия «ADD TO REQUEST» ~13 px** при норме 44 px, и набрана она
  тем же кеглем, регистром и серым, что и «NO. 010» — главное действие страницы
  выглядит как серийный номер. Сделать кнопкой.
- **Выпадающая панель заявки**: нет удержания фокуса, фокус не переносится
  внутрь и не возвращается на кнопку, нет закрытия по Escape, нет `role="dialog"`,
  фон продолжает прокручиваться.
- **Alt-тексты**: базовое и наведённое изображение имеют одинаковый alt —
  название предмета произносится дважды; декоративному поставить `alt=""`.
  Три миниатюры ракурсов подписаны одинаково — переключатель неразличим на слух.
- **Нет `prefers-reduced-motion`** — при том, что анимируются переходы между
  разделами, панель и перекрёстное затухание на 1100 мс. Затухание к тому же
  на телефоне не срабатывает вообще, и второй ракурс там недоступен: добавить
  переключение по тапу и сократить до 350–400 мс.
- **Заголовки заканчиваются на h2**: карточки кодекса, пункты, блоки реестра —
  это `div`. Нет ссылки «к содержимому». Подвал не обёрнут в `<nav>`.
- **Индикатор прокрутки перерисовывает всё приложение** на каждом событии
  прокрутки (629–633: `setState` внутри обработчика). Либо писать ширину
  напрямую, либо убрать полосу — она вообще спорит с тоном бренда.
- **`localStorage` без обработки ошибок** (627, 638): в приватном режиме Safari
  или при заблокированных данных сайта первый вызов прерывает инициализацию,
  второй ломает переключатель языка. Обернуть в `try/catch`.

## 6. Тексты и языки

- **Терминология одного действия.** Сейчас: Request / Request this piece /
  Add to request / Apply / Application. Выбрать одно имя и держать его от кнопки
  до подтверждения (канон — `REQUEST ACCESS`).
- **Армянская шапка ломается**: меню переносится на вторую строку и наезжает
  на страницу, а кнопка «ՀԱՅՏ» дублирует пункт меню «ՀԱՅՏ». Развести названия
  и дать шапке автоматическую высоту.
- **В армянском и русском подвале осталось английское слово «Origin»** — либо
  переводить, либо оформлять как непереводимую марку.
- **Русский**: пункт меню «КОРПОРАТИВНЫМ» — повисший дательный падеж, читается
  как обрывок фразы. Нужно «Корпоративные программы». Строку согласия
  «я понимаю, что предметы продаются по заявке, без скидок» корпоративный
  покупатель читает как закрывающуюся дверь.
- **Галочка согласия** просит покупателя согласиться с коммерческими условиями
  **до того, как ему назвали цену**. Юридической силы у неё нет, а клик стоит
  на самом обрыве воронки. Сделать строкой текста под кнопкой, не условием
  отправки.
- **Описание предмета — девять слов** («The hero of Batch 001. Two days away,
  carried in one hand.»), при трёх абзацах философии на каждой второй странице.
  Соотношение выдаёт, что дом написан раньше, чем сумка. Добавить к каждому SKU:
  что внутрь помещается, размеры, вес, есть ли подкладка, карманы, отделение
  для ноутбука.
- **Проверка родным носителем** русского и армянского перед публикацией
  обязательна. Тексты написаны хорошо, но это не заменяет вычитку.

## 7. Корпоративная страница — пересобрать как B2B-документ

Сейчас это плакат: один экран, три цифры, цитата и кнопка, ведущая в
потребительскую форму. Из примерно двадцати вещей, которые нужны маркетингу
банка и закупке, страница отвечает на четыре.

Добавить:

1. **Ориентир по цене** — «от X ֏ за единицу при 50» и кривая по тиражам
   (50 / 150 / 400+). Это не противоречит правилу «никаких скидок»: цена
   публикуется как кривая, а не как предмет торга. Без ориентира закупка
   не может даже проверить, попадаете ли вы в бюджет.
2. **Реквизиты и условия**: юрлицо, адрес, НДС, счёт, условия оплаты и предоплаты,
   договор (ваш шаблон или их), штраф за срыв срока.
3. **Образец**: платный, с зачётом в заказ, со **знаком клиента**, а не вашим —
   тонкие линии логотипа должны пережить пресс. Плюс образец без тиснения,
   чтобы пощупать кожу и обрез.
4. **Требования к макету**: форматы файлов, минимальная толщина линии, размер
   поля тиснения.
5. **Мощность**: не только минимум 50, но и максимум в месяц. «50+» сейчас
   читается как потолок, а не как порог.
6. **Три уровня подарка** из одной партии и с одним тиснением: картхолдер
   для основной массы, кошелёк для среднего уровня, настольный мат или портфель
   для верхнего. Коробки должны выглядеть роднёй, чтобы за столом не было видно,
   кому что досталось.
7. **Фотографии**: коробка, карточка высокой печати, готовый тираж (пятьдесят
   одинаково оттиснутых предметов на столе), сам процесс — штамп, пресс, контроль
   совмещения. Сейчас на странице, продающей упаковку, нет ни одного снимка
   упаковки.
8. **Имя контакта и телефон в Ереване.** Отдельная форма: компания, роль,
   тираж, дата вручения, интересующий уровень, телефон.
9. **Поэтапная схема** для нового поставщика: 50 сейчас, остальное после приёмки.
   Это то предложение, которое проходит через закупку у обжёгшегося клиента.

**Nairi Insurance называть нельзя** — программа на паузе, а названный
приостановленный клиент хуже, чем ни одного. Показывайте предмет и процесс,
а не список клиентов.

## 8. Что покупатели просили добавить

Из двух прогонов вживую — диаспора и корпоративный клиент.

- **Снимки внутренностей.** Ни у одного из тринадцати предметов нет ни одного
  кадра изнутри. Для дорожной сумки это отказ от покупки сам по себе.
  Нужны: интерьер, вещь в руке или на плече, кадр с ноутбуком внутри — то есть
  масштаб относительно человека.
- **Размеры и вес** в сантиметрах и килограммах. Проходит ли сумка в ручную
  кладь — первый вопрос человека, который летает ежемесячно.
- **Живой человек**: имя, лицо, абзац, мастерская. Одно это даёт доверия больше,
  чем вся страница «Кодекса».
- **Скучный блок**: срок изготовления, доставка и пошлины, возврат и его сроки,
  способ оплаты, гарантия. Настоящие дома проговаривают скучное вслух — это
  добавляет премиальности, а не снимает её.
- **Приглашение зайти**: «в Ереване — приходите посмотреть». Ваше главное
  преимущество перед итальянским поставщиком — что до вас двадцать минут
  на машине, и об этом на сайте нет ни слова.

## 9. Что не трогать

### 9.1. Забрать целиком в любую итоговую версию

- **Реестр Batch 001** (номер · предмет · объект, тринадцать строк, тонкие
  линейки). Конечность партии показана структурой, а не прилагательными. Лучшая
  страница набора.
- **«Кодекс» отдельной страницей** — ограничения, превращённые в опубликованные
  условия.
- **«The price is the price»** — лучшая коммерческая фраза набора; она делает
  отсутствие цены позицией, а не увёрткой.
- **Заявка вместо корзины**: «Not a cart, a request», «Nothing is charged here»,
  «we confirm it, number it, and send it».
- **Макро слепого тиснения** — единственный по-настоящему собственный визуальный
  актив и ровно то, что покупает корпоративный клиент: свой знак в коже.
- **129 ключей перевода** в каждом из EN / RU / HY с точным паритетом, включая
  названия объектов и описание каждого предмета. Самая дорогая в написании часть
  файла.
- **Слой токенов** — цвет, тип, отступы, тени, движение как переменные
  с расписанными ролями и посчитанным контрастом.
- **Память языка между визитами.**
- **Равное отношение к тринадцати предметам**: без цен и с одинаковой съёмкой
  пять неоценённых SKU перестали выглядеть второсортными. Правило на будущее:
  никаких «скоро», «TBD» и пустых состояний. Минимум три кадра на каждый предмет.

### 9.2. Решения, которые принимает владелец, а не исполнитель

Не менять по своей инициативе — вынести на решение:

1. **Светлая земля вместо тёмной.** Канон говорит: обсидиан 70 %. Редизайн
   переворачивает это. Компромисс, который стоит рассмотреть: бумага там, где
   она выигрывает (Дом, Кодекс, реестр, заявка — длинные тексты), обсидиан там,
   где лежит товар (первый экран, коллекция, карточка), потому что кожа —
   зеркальный материал и читается по бликам. На бумаге коричневый вырез без тени
   почти сливается с фоном.
2. **Корзиноподобная механика** (счётчик в шапке, панель, «убрать»). Для
   корпоративного пути она лучше, чем одна заявка на предмет; для частного
   покупателя добавляет шаг. Возможно — оставить мультивыбор только в
   корпоративном сценарии.
3. **Публиковать ли тиражи и остатки.**
4. **Порог корпоративной программы** и реальные сроки по тиражам.
5. **Ремонт, доставка, возвраты** — как политика, а не как фраза на сайте.

Первые три пункта дают сайт, который может принять обращение. Остальные —
сайт, который может закрыть корпоративную программу.
